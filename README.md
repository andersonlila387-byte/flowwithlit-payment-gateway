# Flowwithlit Payment Gateway

Flowwithlit is a payments, wallet, transfer, and payment-link platform for NGN and supported crypto assets.

## Security

Never commit production credentials, private keys, webhook secrets, SMTP passwords, database passwords, or customer data. Copy `.env.example` to a local `.env` file and populate it only in the deployment environment. Local SMTP configuration, runtime mail, private uploads, and key files are excluded by `.gitignore`.
